Acerca de este chatbot

Cómo funciona y qué puede (y no puede) responder

Modo offline (por defecto): busca en los documentos del curso los fragmentos más relevantes para tu pregunta y construye una respuesta a partir de ellos, siempre citando la fuente. No usa internet ni inteligencia artificial generativa — es rápido, privado y funciona sin conexión.

Modo IA (opcional): si activas el interruptor y pegas tu propia llave de API de Anthropic (Claude), el asistente redacta una respuesta más natural, pero igual restringida al contenido recuperado del curso. Tu llave se guarda solo en este navegador y nunca se comparte con nadie más que con Anthropic.

Modo profesor: permite cargar nuevos documentos (pegando texto, subiendo .txt/.md o PDF), editarlos y exportar una nueva versión de este mismo archivo HTML ya actualizada, lista para repartir a los estudiantes.

Este archivo es 100% autocontenido: se puede descargar y abrir directamente en cualquier navegador, sin instalar nada.

🤖 Activar modo IA

Con tu propia llave de la API de Claude (Anthropic)

Esta función llama directamente desde tu navegador a la API de Anthropic usando tu propia llave. Se guarda únicamente en el localStorage de este navegador — nunca se envía a tu docente ni a terceros. Los costos de uso corren por tu cuenta (respuestas cortas cuestan fracciones de centavo).

Puedes obtener una llave en console.anthropic.com → API Keys. Si no tienes una, puedes seguir usando el modo offline sin costo.
